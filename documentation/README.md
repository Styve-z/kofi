# Documentation KOFI

La documentation de transfert se trouve dans les fichiers suivants :

- `architecture.md` : structure logicielle et choix de conception.
- `api.md` : contrats des procédures backend et règles d’autorisation.
- `guides.md` : aide client, professionnel et administrateur.
- `deployment.md` : installation, environnements, sauvegardes, restauration et déploiement.
- `costs.md` : estimation budgétaire et services à activer.
- `release-status.md` : état livré, tests exécutés et éléments bloqués.
